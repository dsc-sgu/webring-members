# Вебкольцо "Живых технологий"
## Что такое вебкольцо?
Вебкольцо - это способ организации сайтов в сети. Участники вебкольца размещают на своих сайтах виджет с ссылками на предыдущего и следующего его участника. Таким образом, посетитель одного сайта, переходя по таким ссылкам, рано или позно посетит все сайты кольца.

## Как присоединиться?
1. Склонируйте репозиторий с помощью `git clone`
2. В конец файла `members.toml` добавьте информацию о своём сайте в следующем формате:
  ```
  [[members]]
  name = <Название вашего сайта>
  url = <Адрес вашего сайта>
  description = <Короткое описание вашего сайта>
  owner = <Кто является владельцем>
  ```
  Поля `description` и `owner` опциональны.

3. Откройте pull request с вашими изменениями.
4. После подтверждения и слияния веток, ваш сайт появится в кольце в течение 12-24 часов.
5. Добавьте на свой сайт виджет вебкольца:
  ```
  <a href="https://webring.alivetech.org/prev?site=YOUR-SITE-URL-HERE">‹ prev</a>
  <a href="https://webring.alivetech.org/">webring</a>
  <a href="https://webring.alivetech.org/random">random</a>
  <a href="https://webring.alivetech.org/next?site=YOUR-SITE-URL-HERE">next ›</a>
  ```
## Healthcheck
Если ваш сайт будет недоступен, то он не будет отображаться в выдаче сайтов вебкольца, однако будет отображаться в списке участников с пометкой "недоступно". Если сайт будет недоступен в течение продолжительного время, он может быть удалён из вебкольца администратором.
